# محلل المقامات الشرقية 🎶

برنامج ويندوز لتحليل الأغاني العربية: بتديله ملف أغنية (أي صيغة) أو **لينك يوتيوب**،
ويطلعلك **المقامات والقرار والنوتات (بالربع تون) والإيقاع**، وكمان **إعدادات الأورج
(Yamaha PSR-2000)** عشان تعزف الأغنية على طول.

---

## التثبيت (الطريقة السهلة)

1. نزّل ملف `MaqamAnalyzer-Setup-1.0.0.exe` من GitHub:
   **Actions ← Build Windows Setup ← آخر تشغيل ناجح ← Artifacts ← MaqamAnalyzer-Setup**
   (بينزل كملف zip فيه الـ Setup).
2. شغّل الـ Setup. لو ويندوز قال "Windows protected your PC" اضغط **More info ← Run anyway**
   (البرنامج مش متوقّع رقميًا لأنه للاستخدام الشخصي).
3. هيتعمل اختصار على سطح المكتب باسم **محلل المقامات**، والإلغاء من
   **Settings ← Apps** زي أي برنامج.

> المساحة: البرنامج حوالي 1.5 جيجا بعد التثبيت (فيه PyTorch وموديل Demucs).

## الاستخدام

| عايز | تعمل إيه |
|---|---|
| تحلل ملف | اسحب الملف على البرنامج، أو **فتح ملف** (Ctrl+O) |
| تحلل من يوتيوب | الصق اللينك في الخانة اللي فوق واضغط **Enter** أو **حلّل اللينك** |
| تسمع من مكان معين | دوس على أي مكان في رسم اللحن، أو على اسم المقطع فوق الرسم |
| تسمع المطرب لوحده / الآلات / الإيقاع | اختار المسار من القائمة جنب شريط التشغيل |
| تتمرن على مهل | غيّر **السرعة** (×0.5، ×0.75 …) |
| زوم في اللحن | عجلة الماوس • اسحب للتحريك • دبل كليك يرجع العرض كامل |
| تصدّر | **MIDI** للحن، **PDF** للتقرير الكامل، و **CSV** للنوتات |

**الصيغ المدعومة:** MP3, WAV, M4A, FLAC, AAC, OGG, OPUS, WMA, AIFF, AMR, APE, WV, AC3, MKA, CAF …
وكمان ملفات الفيديو (MP4, MKV, MOV, WEBM, AVI …) — البرنامج بياخد منها الصوت.
**اللينكات:** يوتيوب (عادي، Shorts، YouTube Music) وأي موقع بيدعمه yt-dlp (ساوند كلاود، فيسبوك …).
اللينك بيتحمّل مرة واحدة ويتحفظ، فلو حللته تاني بيفتح على طول.

### اللوحات الجانبية
- **المقامات:** المقام الأساسي + القرار بالاسم العربي والغربي (مثلاً: دوكاه = ري (D))،
  الأجناس، توزيع النوتات، وكل **المقاطع والتحويلات** بألوان مختلفة — اضغط على أي مقطع يشتغل من عنده.
- **النوتات:** نوتات اللحن بالترتيب مع التوقيت، بالسولفيج (دو ري مي … نص بيمول/نص دييز)
  والحرف الغربي والاسم العربي، والانحراف بالسنت، و**درجة الثقة** — النوتة اللي مش واضحة
  بتتكتب «غير واضحة» بدل التخمين. ◆ = ربع تون.
- **الإيقاع:** اسم الإيقاع (مقسوم، بلدي، صعيدي، ملفوف، وحدة، أيوب، فلاحي، سماعي ثقيل،
  دور هندي، أقساق، جورجينا)، الميزان، السرعة BPM، ورسم الدم والتك.
- **الأورج:** إعدادات **Scale Tune** للـ PSR-2000 (كل نوتة كام سنت)، الـ Master Tune لو
  التسجيل مش على 440، والـ Style والـ Tempo المقترحين — للأغنية كلها ولكل مقطع.

### ضبط الربع تون على الـ PSR-2000
`FUNCTION ← MASTER TUNE/SCALE TUNE ← تاب SCALE TUNE` واختار النوتة واضبطها بالقيمة اللي
في لوحة الأورج (مثلاً السيكا: **مي = ‎-50**). الضبط بيطبق على النوتة في كل الأوكتافات.

## 🎹 وضع التمرين (النوتة والبيانو)

زي فيديوهات تعليم العزف: دوس **«النوتة والبيانو (تمرين)»** فوق رسم اللحن.

- **نوتة موسيقية** للحن (مدرج بمفتاح صول ودليل المقام والميزان والسرعة)، مع علامات **الربع تون** (نص بيمول / نص دييز).
- **البرنامج بيعزف النغمات بنفسه على البيانو** — نفس النوتات المكتوبة — عشان تسمعها وتعزف معاها.
  اختار من قائمة الصوت: **نغمات اللحن على البيانو** لوحدها، أو **البيانو + الموسيقى من غير المطرب**، أو الأغنية الأصلية.
- **مؤشر أخضر** بيمشي على النوتة، و**البيانو اللي تحت بينوّر المفتاح** اللي بيتعزف دلوقتي (Do Re Mi… والعربي تحته).
  الربع تون بيظهر على المفتاح بعلامة ½♭ أو ½♯، والأرقام الزرقا على المفاتيح = ضبط Scale Tune للأورج.
- دوس على أي نوتة في المدرج يشتغل من عندها، وغيّر **السرعة** (×0.5، ×0.75…) عشان تتعلم على مهلك من غير ما الطبقة تتغير.
- نفس الوضع موجود في صفحة **الآيفون**.

> النوتة متكتبة أوتوماتيك من صوت المطرب، فالإيقاع بتاعها تقريبي — خصوصًا في الزخارف والعُرَب.

## 📱 الاستخدام من الآيفون (وضع الموبايل)

التحليل بيحصل على الكمبيوتر، والآيفون بيبقى الشاشة اللي بتتحكم منها — من غير ما تسطّب حاجة على الموبايل.

1. على الكمبيوتر: دوس زرار **الموبايل** فوق ← **تشغيل وضع الموبايل**. هيظهر QR code.
2. الآيفون والكمبيوتر على **نفس الواي فاي**. افتح **الكاميرا** ووجّهها على الكود ودوس على اللينك.
3. هتفتح صفحة في Safari تقدر منها:
   - تلصق لينك يوتيوب أو **ترفع أغنية من الآيفون** (من تطبيق Files).
   - تشوف المقام والقرار والتحويلات والنوتات والإيقاع.
   - تشوف **كيبورد الأورج** والمفاتيح اللي محتاجة Scale Tune عليها مكتوبة — حط الموبايل جنبك وإنت على الأورج.
   - تسمع الأغنية من أي مقطع، أو المطرب لوحده / الإيقاع لوحده، وتبطّأ السرعة.
   - تنزّل الـ PDF والـ MIDI.
4. عشان يبقى زي التطبيق: في Safari دوس **زرار المشاركة ⬆︎ ← Add to Home Screen**.

- أول مرة ويندوز ممكن يسأل عن الـ **Firewall**: اختار **Private networks** واضغط **Allow**.
- تقدر تخلي وضع الموبايل يشتغل تلقائي مع البرنامج (اختيار في نفس النافذة).
- **من برة البيت:** سطّب [Tailscale](https://tailscale.com) (مجاني) على الكمبيوتر والآيفون بنفس الحساب، وهيظهر في نافذة الموبايل عنوان يبدأ بـ `100.` — استخدمه.
- الصفحة محمية بكود سري جوه الـ QR. لو عايز تقفل كل اللينكات القديمة دوس **كود سري جديد**.
- الأغاني اللي من تطبيق Apple Music المحمية مش هينفع ترفعها؛ استخدم ملفات من Files أو لينك يوتيوب.

## الإعدادات (⚙)
- **فصل الصوت بـ Demucs:** أدق بكتير في عزل صوت المطرب. لو اتقفل (أو حصل مشكلة) البرنامج
  بيستخدم فصل أبسط (HPSS) تلقائيًا.
- **استخراج اللحن:** دقيق (CREPE full — موصى به) / سريع (CREPE tiny) / pYIN.
- **مصدر اللحن:** تلقائي، المطرب بس، الآلات بس، أو الأغنية كاملة.
- **مسح الكاش:** فصل الصوت والتحميلات بتتحفظ عشان إعادة التحليل تبقى أسرع.

**الوقت المتوقع** لأغنية 4 دقايق على لابتوب عادي: 4–8 دقايق في أول مرة (Demucs + CREPE)،
وأسرع بكتير في المرات اللي بعدها لنفس الأغنية. اختيار «سريع» بيقلل الوقت جدًا.

## إزاي بيشتغل (المراحل)

| المرحلة | الملف | الطريقة |
|---|---|---|
| 1. تحميل الصوت | `maqam_app/audio_io.py` | soundfile + ffmpeg لأي صيغة |
| 1ب. لينك يوتيوب | `maqam_app/youtube.py` | yt-dlp (أعلى جودة صوت) |
| 2. فصل الصوت | `maqam_app/separation.py` | Demucs htdemucs (احتياطي: HPSS + REPET-SIM) |
| 3. اللحن | `maqam_app/pitch.py` | CREPE (Viterbi + تنعيم أقل من الخانة) أو pYIN |
| 4. الربع تون والضبط | `maqam_app/tuning.py` | اكتشاف انحراف التسجيل عن لا=440 وتصحيحه |
| 5–7. القرار والمقامات والتحويلات | `maqam_app/maqam_detect.py`, `maqam_db.py` | مقارنة الأجناس بتوزيع النوتات (24 درجة) + Viterbi للتحويلات |
| 8. النوتات | `maqam_app/transcribe.py`, `notes.py` | تقطيع النوتات + درجة ثقة |
| 9. الإيقاع | `maqam_app/rhythm.py` | غلاف الدم (ترددات واطية) والتك (عالية) + مطابقة قوالب الإيقاعات |
| الأورج | `maqam_app/organ.py` | Scale Tune للـ PSR-2000 |
| MIDI | `maqam_app/midi_export.py` | الربع تون بـ Pitch Bend (اختياري) |
| PDF | `maqam_app/report.py` | تقرير عربي كامل |
| الواجهة | `maqam_app/ui/` | PySide6 (Qt) — ستايل غامق شبه Procreate، يمين لشمال |
| وضع الموبايل | `maqam_app/mobile/` | سيرفر صغير + صفحة ويب للآيفون (Safari) |
| وضع التمرين | `maqam_app/score.py`, `melody_synth.py`, `ui/practice.py` | تكميم النوتات + MEI + رسم بـ Verovio + بيانو |

**المقامات في قاعدة البيانات:** راست، سوزناك، نيرز، بياتي، حسيني، شوري (بياتي شوري)، صبا،
صبا زمزم، حجاز، حجاز كار، زنجران، نهاوند، كرد، سيكاه، هزام، عراق، عجم، نكريز، نوا أثر، أثر كرد —
ولو المقام متصوّر على قرار تاني البرنامج بيقول (مثلاً: شهناز = حجاز كار على الدوكاه،
فرحفزا = نهاوند على النوا، حجاز كار كرد = كرد على الراست).

## للمطورين

```bash
python -m venv venv && venv\Scripts\activate          # ويندوز
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt pytest
python main.py                 # تشغيل البرنامج
python -m pytest -q tests      # الاختبارات التلقائية
python main.py --selftest      # فحص ذاتي كامل (Demucs + CREPE + PDF + MIDI)
```

**الاختبارات التلقائية** (`tests/`) بتولّد نغمات معروفة (دو ري مي فا صول لا سي + سيكا + أوج + عراق)
على 3 ضبطات مختلفة (440، 446، 434 هرتز) وبتتأكد إن التسمية صح 100% بكل محركات اللحن،
وبتختبر كل المقامات، والتحويل بين مقامين، وكل الإيقاعات على سرعتين، وفتح 11 صيغة صوت وفيديو،
وتصدير MIDI و PDF، وتحليل أغنية تجريبية كاملة.

**بناء الـ Setup:** بيتعمل تلقائيًا على GitHub Actions (`.github/workflows/build-windows.yml`)
مع كل push: بيشغّل الاختبارات، يبني الـ exe بـ PyInstaller، يعمل فحص ذاتي للـ exe نفسه،
وبعدين يعمل الـ Setup بـ Inno Setup. يدويًا على ويندوز:

```bash
python packaging/prepare_build.py                 # موديل Demucs + ffmpeg + deno
pyinstaller packaging/maqam.spec --noconfirm
iscc packaging\installer.iss                      # الناتج في Output\
```

## لو حصلت مشكلة
- الأخطاء بتتسجل في `%LOCALAPPDATA%\MaqamAnalyzer\errors.log` — ابعته مع ملاحظاتك.
- لو تحميل يوتيوب وقف فجأة، غالبًا يوتيوب غيّر حاجة: نسخة جديدة من البرنامج بـ yt-dlp أحدث بتحلها.
